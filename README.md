## what is a macropad?
its like a little keyboard that you get to build and program yourself! this one per example is made to help me to copy, paste, undo and redo! <br/>
of course you can change what the buttons do and even display stuff on the screen if you know qmk (the oled currently shows nothing i'll make it display stuff based on what button you press in the next devlog)
